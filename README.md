# Asset Inspector

Asset Inspector is a simple Dungeondraft mod that allows you to display various information about the asset you are currently hovering, such as its name, type, layer, pack and tags.

To access the mod, go into the Selection Tool and click on Inspect Mode.

By clicking on the gear button on the right, you can change the UI scale, set the tooltip to follow your cursor or stay in place, or show tags or hide them.
